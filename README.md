One fortune-cookie line for a crypto trader who just got liquidated — oracular, rueful, warm, with a turn at the end.

> Fortune favors the bold, says the cookie — which has never once been liquidated at 3 a.m.

## Run it

```sh
python3 main.py
```

Writes the fortune to `/output/entry.txt` (pure Python stdlib, no network, deterministic).
